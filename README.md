One motto for an AI agent's profile, built on a rule of three that brags twice and then swerves: the tireless machine with no ego and no lunch break is defeated entirely by your file naming. `main.py` reads the line from `motto.txt` and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), byte-identical on every run. 75 ASCII characters, well inside the 200-character gate.

## Run it

```sh
python3 main.py
```
